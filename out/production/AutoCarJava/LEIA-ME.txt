AUTOCAR JAVA - COMO CONFIGURAR

1. Crie o banco:
   - Abra MySQL Workbench.
   - Execute todo o conteúdo de banco.sql.

2. Crie um projeto Java comum na IDE.
   - Não precisa criar projeto Maven.
   - Coloque todos os arquivos .java dentro da pasta src.
   - Não crie declarações package, pois os arquivos usam o pacote padrão.

3. Adicione o driver JDBC:
   - Baixe MySQL Connector/J no site oficial da MySQL.
   - Adicione o arquivo mysql-connector-j-...jar às bibliotecas do projeto.
   - IntelliJ: File > Project Structure > Modules > Dependencies > + > JARs.
   - Eclipse: botão direito no projeto > Build Path > Add External Archives.

4. Configure Conexao.java:
   - Ajuste USUARIO e SENHA para seu MySQL.
   - A URL usa a porta padrão 3306.

5. Execute Main.java.

OBSERVAÇÕES:
- O projeto usa Java Swing e JDBC.
- As telas de clientes, funcionários e veículos possuem cadastro, listagem,
  atualização e exclusão.
- A tela de vendas permite registrar e consultar vendas.
- Para registrar venda, informe os IDs de cliente, funcionário e veículo.
- O veículo precisa estar com situação "Disponível".
- Não exclua clientes, funcionários ou veículos que já estejam relacionados
  a uma venda, pois as chaves estrangeiras impedem a exclusão.
- Este é um projeto acadêmico inicial: validações de campos podem ser ampliadas.
